# fokuskonten-assets-ebook

Repositori sekoci CDN khusus aset cover WebP portal perpustakaan e-book FokusKonten.

Berisi cover buku 3D studio (800x800 px, WebP Q90) untuk 16.600+ naskah e-book.

Disajikan via **jsDelivr Edge CDN**:
```
https://cdn.jsdelivr.net/gh/mcjobs-id/fokuskonten-assets-ebook@main/ebook/{SKU}/{SKU}_cover.webp
```
